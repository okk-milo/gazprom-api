# gazprom-api

Серверный компонент системы анализа телефонных разговоров: организует обработку аудиозаписей, взаимодействие с сервисами распознавания речи и языкового анализа, хранение и предоставление результатов

Актуальная реализация: [ветка task/DEV-614](https://github.com/okk-milo/gazprom-api/tree/task/DEV-614)

## Возможности

- Управление сотрудниками, сделками, загрузками и историей проверок
- Координация распознавания речи, определения ролей участников и оценки риска мошеннического воздействия
- Предоставление статусов, промежуточной расшифровки, динамики риска и оснований итоговой оценки
- Отдельный API для данных раздела «Выгорание»

## Технологии и взаимодействие

Стек: NestJS, TypeScript, PostgreSQL и S3-совместимое хранилище

Аудиозаписи хранятся в S3, метаданные и результаты - в PostgreSQL

Распознавание речи выполняет `okk-asr`, языковой анализ - `okk-llm`; API координирует эти этапы и передаёт результаты в [gazprome](https://github.com/okk-milo/gazprome/tree/task/DEV-614)

## Качество и ограничения

На внутренней выборке ROC AUC оценки выгорания составил около 0,87; выборка защищена условиями NDA

*В выборке исходных датасетов часть аудиозаписей содержит заглушенные речевые фрагменты, что снижает разборчивость речи и полноту доступного контекста, ограничивая возможности автоматического анализа и оценки его качества*
